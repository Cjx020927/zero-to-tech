# 打地鼠游戏 + Python 自动化脚本

一个结合网页小游戏与桌面自动化的趣味项目，包含两个模块：

1. **网页版打地鼠小游戏** — 基于原生 HTML + CSS + JavaScript，浏览器直接打开即玩
2. **Python 自动化瞄准脚本** — 基于 OpenCV + mss + pyautogui 实现屏幕模板识别，自动找地鼠并模拟鼠标点击

## 目录结构

```
26-09-11/
├── 26-09-18.html   # 网页版打地鼠游戏（入口）
├── 26-09-18.css    # 游戏样式
├── main.py         # Python 自动化脚本
├── mouse.png       # 地鼠图片（同时作为游戏 CSS 背景与 Python 模板）
└── README.md       # 本文件
```

## 一、网页版打地鼠游戏

直接用浏览器打开 `26-09-18.html` 即可游玩。

### 功能

- 9 宫格地洞，地鼠随机冒头
- **难度选择**：简单 / 普通 / 困难（影响停留时间、出现频率、同时最多数量）
- **连击系统**：连续命中加成（每 5 连击 +1 分）
- **最高分**：使用 `localStorage` 持久化
- **击中动画**：地鼠缩回 + 金色波纹效果
- **音效**：基于 Web Audio API，命中 / 未命中 / 游戏结束不同提示音（可关闭）
- **暂停 / 继续**：按钮或空格键
- **游戏结束弹窗**：替代 `alert`，支持一键重玩

### 操作

- 鼠标点击冒出的地鼠得分
- 点击空洞会清零连击
- 空格键：暂停 / 继续

## 二、Python 自动化脚本

### 依赖

```bash
pip install opencv-python numpy pyautogui mss
```

### 使用

```bash
# 默认参数（使用内置游戏区域与阈值 0.75）
python main.py

# 自定义阈值（更低=更宽松匹配，更高=更严格）
python main.py --threshold 0.8

# 自定义游戏窗口区域 "left,top,width,height"
python main.py --monitor "36,149,675,675"

# 启动时自动点击开始按钮 "x,y"
python main.py --start "370,180"

# 关闭可视化窗口，运行更快
python main.py --no-view

# 指定其他模板图片
python main.py --template other_mole.png
```

按键盘 `q` 退出识别窗口，`Ctrl+C` 退出脚本。

### 工作流程

1. 用 `mss` 截取游戏区域
2. `cv2.matchTemplate` 模板匹配找地鼠
3. **NMS（非极大值抑制）** 去除同一地鼠的重复框
4. 对每个独立地鼠判断冷却时间（同一地鼠 0.3s 内不重复点击）
5. `pyautogui` 模拟点击地鼠中心
6. 实时显示绿色识别框 + 命中计数

### 制作自己的模板

1. 打开游戏截图地鼠露头状态
2. 用画图 / Snipaste 等裁剪出地鼠图片
3. 保存为 `mouse.png`（或其他路径，用 `--template` 指定）

### 提示

- 不同分辨率 / 浏览器缩放下，游戏区域坐标会变，请用 `--monitor` 调整
- 阈值过高会漏检，过低会误点，建议从 `0.75` 开始调整
- 模板尽量是地鼠露出后的最大尺寸且边缘清晰
